## 📌 About This Repository

This repository contains my **Machine Learning learning journey**, including implementations of algorithms, data preprocessing techniques, mathematical concepts, and practical experiments.

The goal is to understand **how Machine Learning algorithms work**, implement them using Python, and gradually build a strong foundation for developing real-world ML applications.
